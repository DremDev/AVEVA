# AVEVA PML Toolkit

Automation tools developed for AVEVA E3D / PDMS.

## Projects

### Weld Sequential Renamer
Automatic WELD numbering utility.

### Tee Weld Auto Naming
Automatic weld naming around TEE components.

### CSV Attribute Importer
Bulk update of AVEVA native attributes from CSV files.

## Technologies

- AVEVA E3D
- AVEVA PDMS
- PML1
- Database Automation
- CSV Processing
